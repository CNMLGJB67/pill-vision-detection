# 药片定位视觉检测系统

基于 Python + OpenCV 的工业机器视觉定位系统，面向药片生产、质检环节，实现药片的自动化图像采集、轮廓提取与精准定位，输出药片外接矩形坐标，为后续分拣、尺寸测量、缺陷检测等工序提供核心坐标数据支持。

- **定位成功率 100%**（6 组不同角度、不同摆放位置的白色药片样本，6/6）
- **坐标误差平均 ≤1 像素**（像素尺寸 3.75μm，实际物理误差 ≤3.75μm）
- **单图处理耗时平均约 0.32 秒**

## 系统架构

系统采用「硬件采集层 + 算法处理层 + 结果输出层」三层架构：

![系统架构图](assets/architecture.png)

- 图像采集模块：工业相机（CMOS 全局快门）、定焦工业镜头、环形 LED 光源
- 数据处理模块：图像预处理单元、轮廓分析单元、坐标计算单元
- 结果输出模块：可视化显示窗口、坐标数据打印、二次开发接口

## 算法流程

![算法流程图](assets/flowchart.png)

1. 读取药片图像
2. 彩色图像转灰度图（`cv2.cvtColor`）
3. 高斯模糊降噪（5×5 核，`cv2.GaussianBlur`）
4. 二值化分割（阈值 191，`cv2.threshold`；不同样本调试区间为 145–191，定版取 191）
5. 形态学闭运算（9×9 核，`cv2.morphologyEx`），补全轮廓细微断裂
6. 提取外部轮廓（`cv2.findContours`，`RETR_EXTERNAL`）
7. 轮廓面积筛选（2000–120000），过滤噪点与背景轮廓
8. 选取最大面积轮廓，计算外接矩形（`cv2.boundingRect`）；无有效轮廓时回退选取全体轮廓中面积最大者
9. 输出左上角 + 右下角坐标，绘制矩形框并显示图像

核心参数：

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 高斯核 | 5×5 | 降噪并保留药片边缘 |
| 二值化阈值 | 191 | 分割白色药片与浅灰背景 |
| 形态学核 | 9×9 | 闭运算补全轮廓断裂 |
| 面积筛选 | 2000–120000 px | 目标药片轮廓的面积范围 |
| 矩形框线宽 | 4 | 白色（255, 255, 255） |

## 环境与运行

环境要求（Windows 10/11 或 Ubuntu 20.04 均可）：

- Python 3.8–3.10（推荐 3.9）
- opencv-python 4.8.0.74
- numpy 1.24.3

安装依赖：

```bash
pip install opencv-python==4.8.0.74 numpy==1.24.3
# 或
pip install -r requirements.txt
```

运行：

```bash
# 将待定位的药片图像与代码放在同一文件夹，按需修改代码中的图像文件名
python dzy.py
```

运行后自动弹出图像窗口显示框选结果，控制台打印左上角与右下角坐标，按任意键关闭窗口。
